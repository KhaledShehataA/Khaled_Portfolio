# Khaled's Portfolio

A personal portfolio website built with plain HTML, SCSS/CSS and JavaScript (2022). It is a single page with sections for Home, About, Portfolio, Blogs and Contact, with section switching done in JavaScript. Several sections still hold template placeholder text (lorem ipsum and sample numbers) and need real content.

## Tech stack
- HTML5
- SCSS compiled to CSS (`styles/styles.scss`, `styles/_media.scss`)
- Vanilla JavaScript (`app.js`)

## Requirements
- A web browser. Node.js and a Sass compiler are only needed if you want to edit the SCSS.

## Install and run
```bash
git clone https://github.com/KhaledShehataA/Khaled_Portfolio.git
cd Khaled_Portfolio
```
Open `index.html` in a browser. To change styles, edit `styles/styles.scss` and recompile it to `styles/styles.css` with Sass.

## Environment variables
None.

## Usage
Use the side buttons to move between the Home, About, Portfolio, Blogs and Contact sections.
